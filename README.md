# Batcomputer Website

This repository's website entry point is:

- `index.html` (redirects to `batcomputer_console.html`)

For GitHub Pages, publish this repository and GitHub will load `index.html` automatically.

## Local run (full Alfred features)

```powershell
alfred
```

The full live assistant features (chat APIs, coding-agent APIs, weather routing, etc.) require the local Flask server.
