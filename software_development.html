Featured Engineering Projects

Batcomputer Operations Platform

A full-stack operations platform connecting six engineering domains through shared users, workspaces, assets, workflow events, and audit records.

Architecture

React and TypeScript communicate with a versioned FastAPI REST API backed by SQLAlchemy, Alembic, and PostgreSQL.

Engineering Features

  • Secure password hashing with Argon2
  • Expiring authentication tokens
  • Server-side role-based access control
  • Workspace ownership and data isolation
  • Immutable audit events
  • Pagination, filtering, and validation
  • Structured logging and request correlation
  • Health and readiness endpoints
  • Docker-based local environment
  • Strict automated CI checks

Current Availability

The source currently runs locally through Docker Compose. A public GitHub repository and hosted demonstration have not been configured yet.

Alfred AI Integration

Alfred is an approval-oriented assistant integration designed around explicit status reporting, workspace safety, and auditable user intent.

  • Typed FastAPI status and intent endpoints
  • Workspace membership checks
  • Rate-limited intent requests
  • Explicit approval requirements
  • Auditable request metadata
  • No fake AI or echo-response fallback

When Ollama is not configured, Alfred reports that it is unavailable. Requests are never falsely reported as executed.

Orbital Mission Planner

An educational two-dimensional orbital simulator for comparing deterministic numerical integration methods.

  • Configurable central body and initial conditions
  • Runge-Kutta 4 integration
  • Velocity-Verlet integration
  • Trajectory visualization
  • Energy-error comparison
  • Saved and shareable scenarios
  • Tests against known circular-orbit behavior

This project is intended for education and software-engineering demonstration. It is not flight-grade software.
