Network Prototypes

Network Software

Five dependency-light prototypes demonstrate subnet calculations, bounded reachability checks, sample telemetry summaries, SQLite inventory synchronization, and review-only configuration planning.

Demonstrated scope

  • Standard-library CIDR and address calculations
  • Bounded operating-system ping checks for one target
  • Health classification over built-in sample telemetry
  • JSON device records synchronized into a local SQLite database
  • Configuration commands rendered as a plan without network connections

Current limitations

There is no cloud platform, SNMP polling, SSH or Netmiko connection, real-time dashboard, API retrieval, managed database, container deployment, or production monitoring. The inventory example is the only project here that persists data, and it uses local SQLite.

Projects

  • Telemetry Summary Prototype — Classifies two built-in sample records and prints JSON; it does not poll SNMP or render a live dashboard.
  • Ping Reachability Analyzer — Runs a bounded ping for one host and reports reachability; it is not continuous or multihost monitoring.
  • Subnet Calculator — Computes network, broadcast, mask, address count, and usable host range for IPv4 CIDR input.
  • JSON-to-SQLite Inventory — Reads device data from a local JSON file and upserts it into SQLite; it does not call network APIs.
  • Configuration Plan Utility — Generates a reviewable plan from local JSON targets and a command; it does not connect to or configure devices.
