Cyber Security Training Prototype

OWASP Juice Shop Testing

A local string-reflection check for illustrating one input-handling concept without contacting Juice Shop or another web application.

Evidence snapshot

Source: Cybersecurity\owasp-juice-shop-testing

Run from repository root: python "Cybersecurity\owasp-juice-shop-testing\main.py"

Validation: Fully local and deterministic; performs no file, network, browser, or target interaction.

Implemented

  • Accepts probe and response strings through command-line options
  • Checks whether the probe appears unescaped in the response
  • Prints a small structured training result

Limitations

This does not test OWASP Juice Shop, run exploits, cover the OWASP Top 10, or assess authentication, access control, injection, or browser behavior.
