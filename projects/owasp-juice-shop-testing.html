OWASP Juice Shop Testing

Performed hands-on web application security testing against OWASP Juice Shop, a deliberately vulnerable training application, aligned with the OWASP Top 10. Practiced identifying and documenting injection flaws, broken authentication, insecure direct object references, and cross-site scripting to build real-world offensive and defensive security awareness in a safe, legal, self-hosted environment.

Code Example

# Example: scripted detection check for a reflected XSS field
# against a locally-hosted Juice Shop instance (127.0.0.1)
import requests

TARGET = "http://127.0.0.1:3000/rest/products/search"
PROBE = "<script>test</script>"

def check_reflected_input(target, probe):
    response = requests.get(target, params={"q": probe}, timeout=5)
    reflected = probe in response.text
    return {
        "endpoint": target,
        "probe": probe,
        "reflected_unescaped": reflected,
        "status_code": response.status_code,
    }

Project architecture

The simulator sends a controlled query to a locally hosted Juice Shop endpoint, checks whether the probe is reflected in the response, and records the endpoint, probe, reflection result, and HTTP status.

  • Request construction isolates the target and test input.
  • Response inspection checks for unescaped reflection.
  • Structured findings connect evidence to remediation.

Features and expansion

Current features include a parameterized request, local Juice Shop targeting, response reflection checks, and evidence reporting. Next additions should include an OWASP test catalog, encoding checks, authenticated test flows, evidence capture, and remediation verification.
