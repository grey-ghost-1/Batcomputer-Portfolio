Project architecture

The portfolio combines Flask routing with static HTML project pages, shared CSS, browser JavaScript, Alfred chat, and explicit proposal-review controls to present technical work through an interactive HUD.

  • Flask maps clean routes to category and project pages.
  • Shared CSS keeps the visual language consistent.
  • Browser JavaScript powers chat, panels, voice, and review controls.

Features and expansion

Current features include responsive project presentation, category navigation, project detail pages, embedded Alfred chat, voice support, and proposal review. Next additions should include project metadata, automated link checks, accessibility testing, image-backed demonstrations, analytics, and a published repository link.
