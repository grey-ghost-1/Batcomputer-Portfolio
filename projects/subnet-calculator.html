Network Utility

Subnet Calculator

A dependency-free command-line utility that reports network boundaries and usable host information for IPv4 or IPv6 CIDR input.

Evidence snapshot

Source: Network\subnet-calculator

Run from repository root: python "Network\subnet-calculator\main.py" 192.168.1.0/24

Validation: Fully local, deterministic, and side-effect free.

Implemented

  • Standard-library ipaddress parsing
  • Network, broadcast, and netmask output
  • Address count, usable-host count, and first/last host output

Limitations

This is a calculator only. It does not discover networks, reserve addresses, modify configurations, persist plans, or connect to infrastructure.
