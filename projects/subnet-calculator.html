Subnet Calculator

Implemented a Python CLI utility that computes CIDR ranges, usable host counts, broadcast addresses, and network boundaries. Designed to support subnet planning, network segmentation, and infrastructure documentation.

Code Example

import ipaddress

def describe_subnet(cidr):
    network = ipaddress.ip_network(cidr, strict=False)
    hosts = list(network.hosts())
    return {
        "network_address": str(network.network_address),
        "broadcast_address": str(network.broadcast_address),
        "netmask": str(network.netmask),
        "usable_hosts": len(hosts),
        "first_usable": str(hosts[0]) if hosts else None,
        "last_usable": str(hosts[-1]) if hosts else None,
    }

Project architecture

The calculator passes a CIDR string to Python's ipaddress module, derives network boundaries and usable hosts, and returns a complete subnet description.

  • ip_network normalizes the requested network.
  • Address properties provide network, broadcast, and netmask values.
  • Host iteration derives first, last, and usable host counts.

Features and expansion

Current features include CIDR parsing, network and broadcast addresses, netmask calculation, usable-host counts, and boundary addresses. Next additions should include IPv6 support, CLI argument validation, table output, subnet division, and edge-case tests.
