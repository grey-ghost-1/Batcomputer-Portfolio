System Health Checker

Engineered an automated scanning utility that evaluates system updates, driver status, storage capacity, and network configuration. Consolidated results into clear reports, enabling faster identification of system vulnerabilities and maintenance needs.

Code Example

import shutil
import subprocess

def check_disk_space(path="C:\\"):
    total, used, free = shutil.disk_usage(path)
    return {"total_gb": total // (2**30), "free_gb": free // (2**30)}

def check_pending_updates():
    result = subprocess.run(
        ["powershell", "-Command", "Get-WindowsUpdate"],
        capture_output=True, text=True
    )
    return result.stdout.strip() or "No pending updates found"

def build_health_report():
    return {
        "disk": check_disk_space(),
        "updates": check_pending_updates(),
    }

Project architecture

The checker combines disk-capacity inspection with a PowerShell update query, then consolidates the results into one maintenance report for a Windows workstation.

  • shutil reads storage capacity.
  • subprocess invokes the system update check.
  • A report builder combines independent checks.

Features and expansion

Current features include free-space measurement, pending-update inspection, and consolidated reporting. Next additions should include driver status, network configuration, explicit command timeouts, structured JSON output, and mocked subprocess tests.
