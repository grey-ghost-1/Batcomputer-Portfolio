IT Support Prototype

System Health Checker

A read-only disk-space check that compares free bytes for one path against a fixed 10 GB threshold.

Evidence snapshot

Source: IT Support\system-health-checker

Run from repository root: python "IT Support\system-health-checker\main.py" .

Validation: Reads local disk-usage values and writes no files or settings.

Implemented

  • Path input with current-directory default
  • shutil.disk_usage free-space retrieval
  • Healthy or attention status based on a fixed threshold

Limitations

No update, driver, CPU, memory, network configuration, security, SMART-health, or maintenance checks are included.
