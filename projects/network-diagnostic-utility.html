IT Support Prototype

Network Diagnostic Utility

A bounded command-line diagnostic that resolves one host through DNS and invokes the operating system's ping command once.

Evidence snapshot

Source: IT Support\network-diagnostic-utility

Run from repository root: python "IT Support\network-diagnostic-utility\main.py" localhost

Validation: Spawns a bounded system ping process and performs DNS/ICMP activity; the default target remains local.

Implemented

  • IPv4 resolution with socket.gethostbyname
  • OS-aware ping flag selection
  • Eight-second subprocess timeout and reachability result

Limitations

No traceroute, parsed latency value, repeated monitoring, packet-loss analysis, DNS-record inspection, configuration diagnosis, or remediation is implemented.
