Network Diagnostic Utility

Implemented a suite of network diagnostic tools including ping, traceroute, DNS lookup, and latency measurement. Designed to assist in identifying connectivity issues, routing problems, and DNS misconfigurations in real-world support environments.

Code Example

import subprocess
import socket

def ping_host(host, count=4):
    result = subprocess.run(
        ["ping", "-n", str(count), host], capture_output=True, text=True
    )
    return result.stdout

def resolve_dns(host):
    try:
        return socket.gethostbyname(host)
    except socket.gaierror as exc:
        return f"DNS resolution failed: {exc}"

def traceroute(host):
    result = subprocess.run(["tracert", host], capture_output=True, text=True)
    return result.stdout

Example

Sample diagnostic run for a reported connectivity issue:

$ python netdiag.py contoso.com

Traceroute: 8 hops, last hop timed out at hop 6 (possible routing issue)

Project architecture

The utility separates common support diagnostics into focused operations: ping a host, resolve its address, and run a Windows traceroute, returning raw command output or a clear DNS failure.

  • subprocess handles ping and tracert commands.
  • socket performs DNS resolution.
  • Each diagnostic can be run independently.

Features and expansion

Current features include ping, DNS lookup, traceroute, and readable command output. Next additions should include command timeouts, structured latency and loss parsing, platform adapters, batch targets, and tests for DNS and process failures.
