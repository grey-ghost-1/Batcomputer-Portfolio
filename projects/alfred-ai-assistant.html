Alfred AI Assistant

Engineered a fully local Python-based AI assistant featuring wake-word detection, speech-to-text, text-to-speech, and a Flask backend. Integrated modular automation functions to execute system tasks, retrieve information, and interact with desktop workflows, demonstrating strong capability in Python automation and AI-driven utility development. The assistant runs entirely on-device, keeping conversation state, memory, and desktop actions local rather than routed through third-party cloud services.

Code Example

import speech_recognition as sr
import pyttsx3
from flask import Flask, request, jsonify

recognizer = sr.Recognizer()
speaker = pyttsx3.init()
app = Flask(__name__)

WAKE_WORD = "alfred"

def listen_for_wake_word(source):
    audio = recognizer.listen(source, phrase_time_limit=3)
    try:
        phrase = recognizer.recognize_google(audio).lower()
        return WAKE_WORD in phrase
    except sr.UnknownValueError:
        return False

def speak(text):
    speaker.say(text)
    speaker.runAndWait()

Project architecture

Alfred combines speech recognition, text-to-speech, a wake-word gate, and a Flask endpoint into a local assistant workflow that can route requests to desktop automation and information services.

  • Speech recognition captures the spoken request.
  • Wake-word detection controls when listening is actionable.
  • Flask exposes the assistant request endpoint.
  • Text-to-speech returns the response through the local speaker.

Features and expansion

Current features include wake-word detection, speech-to-text, text-to-speech, Flask routing, local execution, and desktop workflow integration.
