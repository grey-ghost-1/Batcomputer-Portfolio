Flagship Platform

Batcomputer Operations Platform

A separate FastAPI modular monolith for tenant-isolated operational assets, workflows, audit evidence, and approval-only Alfred intents.

Evidence snapshot

Source: platform

Run from repository root: Set-Location platform; python -m uvicorn app.main:app

Validation: API tests exercise auth, RBAC, isolation, CRUD, workflows, audit immutability, validation, health, and Alfred boundaries.

Implemented

  • FastAPI, Pydantic, SQLAlchemy, Alembic, PostgreSQL configuration, and SQLite test support
  • Argon2 passwords, expiring signed access tokens, role checks, workspace scoping, structured request logs, and correlation IDs
  • Six-category assets and work items, guarded transitions, pagination/filtering, audit events, health/readiness, OpenAPI, and operator UI

Limitations

No hosted deployment, MFA, SSO, password reset, refresh/revocation flow, external integrations, background execution, rate limiting, or Alfred generation/execution is implemented. See platform\README.md for operations guidance.
