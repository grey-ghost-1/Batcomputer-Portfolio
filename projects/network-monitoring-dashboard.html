Network Monitoring Dashboard

A static telemetry-summary prototype that classifies two built-in device records and prints aggregate JSON.

Evidence snapshot

Source: Network\network-monitoring-dashboard

Run from repository root: python "Network\network-monitoring-dashboard\main.py"

Validation: Fully local and deterministic; uses only built-in sample data and writes nothing.

Implemented

  • DeviceStatus dataclass
  • Healthy and alert classification for two sample devices
  • JSON summary counts

Limitations

There is no SNMP dependency, live polling, dashboard server, visualization, historical storage, alert delivery, device connection, or real-time data.
