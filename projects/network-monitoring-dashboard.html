Network Monitoring Dashboard

Built an SNMP-powered monitoring dashboard that tracks device uptime, latency, bandwidth usage, and alert conditions. Integrated real-time polling and visualizations to support network operations and infrastructure oversight.

Code Example

from pysnmp.hlapi import (
    getCmd, SnmpEngine, CommunityData, UdpTransportTarget,
    ContextData, ObjectType, ObjectIdentity
)

def get_sys_uptime(host, community="public"):
    iterator = getCmd(
        SnmpEngine(),
        CommunityData(community),
        UdpTransportTarget((host, 161), timeout=2, retries=1),
        ContextData(),
        ObjectType(ObjectIdentity("1.3.6.1.2.1.1.3.0")),
    )
    error_indication, error_status, _, var_binds = next(iterator)
    if error_indication or error_status:
        return None
    return var_binds[0][1]

Project architecture

The dashboard polls SNMP-enabled devices, collects uptime, latency, bandwidth, and alert data, then presents the results as an operational monitoring view.

  • SNMP polling provides device telemetry.
  • Polling results are normalized into monitoring records.
  • Alert conditions surface degraded or unreachable devices.

Features and expansion

Current features include uptime, latency, bandwidth, alert tracking, and real-time monitoring. Next additions should include device profiles, polling intervals, historical storage, alert acknowledgements, dashboard filters, and test fixtures for unreachable devices.
