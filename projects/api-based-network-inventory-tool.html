Network Data Prototype

API-Based Network Inventory Tool

A local JSON-to-SQLite synchronization prototype for storing simple device inventory records.

Evidence snapshot

Source: Network\api-based-network-inventory-tool

Run from repository root: python "Network\api-based-network-inventory-tool\main.py" path\to\inventory.json

Validation: Requires a user-supplied JSON file and creates or updates inventory.db in the working directory.

Implemented

  • Local JSON device loading
  • SQLite table creation and upsert behavior
  • Structured output of stored inventory rows

Limitations

No network API retrieval, authentication, discovery, topology mapping, remote database, scheduler, or change notification is implemented.
