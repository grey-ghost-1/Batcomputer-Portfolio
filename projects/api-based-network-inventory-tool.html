API-Based Network Inventory Tool

Built a system that retrieves device information from network APIs and stores it in a structured database. Enables automated inventory tracking, device classification, and infrastructure mapping for network operations.

Code Example

import sqlite3
import requests

def fetch_devices(api_url, token):
    headers = {"Authorization": f"Bearer {token}"}
    response = requests.get(api_url, headers=headers, timeout=10)
    return response.json()["devices"]

def store_inventory(devices, db_path="inventory.db"):
    conn = sqlite3.connect(db_path)
    conn.execute("""
        CREATE TABLE IF NOT EXISTS devices (
            id TEXT PRIMARY KEY, name TEXT, ip TEXT, type TEXT, last_seen TEXT
        )
    """)
    for device in devices:
        conn.execute(
            "INSERT OR REPLACE INTO devices VALUES (?, ?, ?, ?, ?)",
            (device["id"], device["name"], device["ip"], device["type"], device["last_seen"]),
        )
    conn.commit()
    conn.close()

Project architecture

The inventory tool retrieves device records from a network API, maps the returned fields into a SQLite schema, and upserts records so repeated syncs keep the inventory current.

  • Bearer-token requests retrieve remote device data.
  • SQLite stores identity, name, IP, type, and last-seen fields.
  • Insert-or-replace behavior supports repeatable synchronization.

Features and expansion

Current features include authenticated API retrieval, structured device records, SQLite persistence, inventory updates, and new-device detection. Next additions should include pagination, retries, schema validation, change history, token redaction, and export formats.
