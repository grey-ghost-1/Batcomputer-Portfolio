Personal Dashboard Web App

Built a Flask/FastAPI-powered dashboard that aggregates system metrics, weather data, and network information through REST APIs. Implemented dynamic UI components, real-time data polling, and modular API endpoints to create an interactive monitoring interface suitable for personal or operational use.

Code Example

from fastapi import FastAPI
import psutil
import requests

app = FastAPI()

@app.get("/api/metrics")
def get_metrics():
    return {
        "cpu_percent": psutil.cpu_percent(interval=0.5),
        "memory_percent": psutil.virtual_memory().percent,
        "disk_percent": psutil.disk_usage("/").percent,
    }

@app.get("/api/weather")
def get_weather(city: str = "Detroit"):
    response = requests.get(
        "https://api.open-meteo.com/v1/forecast",
        params={"latitude": 42.33, "longitude": -83.05, "current_weather": True},
        timeout=5,
    )
    return response.json()["current_weather"]

Project architecture

The dashboard aggregates system metrics and weather data through API routes, transforms responses into dashboard-ready values, and presents them through dynamic UI components with periodic polling.

  • REST endpoints isolate metrics and weather retrieval.
  • psutil supplies local CPU, memory, and disk values.
  • Polling keeps the operational view current.

Features and expansion

Current features include metrics aggregation, weather retrieval, REST APIs, dynamic components, and real-time polling. Next additions should include authentication, caching, request timeouts, historical charts, configurable locations, and degraded-service states.
