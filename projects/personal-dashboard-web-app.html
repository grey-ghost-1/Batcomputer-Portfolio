Software Data Prototype

Personal Dashboard Web App

A one-shot command-line snapshot that prints the operating-system name and disk-use percentage as JSON.

Evidence snapshot

Source: Software Automation\personal-dashboard-web-app

Run from repository root: python "Software Automation\personal-dashboard-web-app\main.py" .

Validation: Reads local disk-usage values and writes no files or settings.

Implemented

  • Path input with current-directory default
  • Disk-use percentage calculation
  • JSON output with host type; CPU and memory fields are explicitly null

Limitations

No Flask or FastAPI server, web UI, REST endpoint, polling, weather data, network metrics, CPU measurement, memory measurement, persistence, or visualization is implemented.
