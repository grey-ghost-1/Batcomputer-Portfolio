Messaging/RCS Diagnostic Simulator

Built a simulation tool to test RCS/SMS fallback behavior, carrier routing issues, and message delivery reliability. Used to analyze inconsistent messaging performance across devices and networks, improving understanding of telecom protocols and troubleshooting methods.

Code Example

import random
import time

class MessageSimulator:
    def __init__(self, rcs_available=True, failure_rate=0.1):
        self.rcs_available = rcs_available
        self.failure_rate = failure_rate

    def send(self, message):
        if self.rcs_available and random.random() > self.failure_rate:
            return {"protocol": "RCS", "status": "delivered", "latency_ms": random.randint(200, 600)}

        # Simulate fallback to SMS when RCS fails or is unavailable
        time.sleep(0.1)
        return {"protocol": "SMS", "status": "delivered (fallback)", "latency_ms": random.randint(800, 2000)}

Project architecture

The simulator models message delivery by checking RCS availability and a configurable failure rate, then selecting RCS or SMS fallback and returning protocol, status, and latency data.

  • MessageSimulator owns delivery state and policy.
  • Randomized failure models intermittent service conditions.
  • Structured results make protocol fallback observable.

Features and expansion

Current features include RCS availability modeling, configurable failures, SMS fallback, simulated latency, and delivery summaries. Next additions should include seeded simulations, carrier profiles, retry rules, batch reports, and tests for deterministic fallback behavior.
