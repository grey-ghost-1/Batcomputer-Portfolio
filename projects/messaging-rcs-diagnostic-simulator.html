Messaging/RCS Diagnostic Simulator

A deterministic local if/else simulation that shows an RCS delivery result or an SMS fallback result.

Evidence snapshot

Source: IT Support\messaging-rcs-diagnostic-simulator

Run from repository root: python "IT Support\messaging-rcs-diagnostic-simulator\main.py" hello --rcs-unavailable

Validation: Fully local and deterministic; no message, carrier, device, or network interaction occurs.

Implemented

  • Message text input
  • Boolean RCS-availability flag
  • Canned channel, delivery state, and latency output

Limitations

This does not implement RCS or SMS protocols, carrier routing, delivery verification, device testing, randomized failures, or real latency measurement.
