Source: algorithms-quality

Run from repository root: python -m pytest algorithms-quality\tests -q

Validation: Executable tests cover empty, duplicate, invalid, missing, ordering, mutation-safety, and deterministic-path behavior.

Implemented

  • Arrays/strings, hash maps, a queue from stacks, binary search tree, and graph BFS
  • Merge sort, binary search, recursive backtracking permutations, and dynamic-programming coin change
  • Complexity table, trade-offs, explicit limits, and strict CI execution

Limitations

The tree is unbalanced, permutation output grows factorially, graph edges are unweighted, and these educational implementations do not replace optimized standard-library or production packages.
