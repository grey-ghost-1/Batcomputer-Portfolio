Network Plan-Only Prototype

Automated Device Configuration Utility

A review-only planner that combines local device records with supplied configuration commands and prints a proposed plan.

Evidence snapshot

Source: Network\automated-device-configuration-utility

Run from repository root: python "Network\automated-device-configuration-utility\main.py" path\to\targets.json --command "vlan 20"

Validation: Read-only and requires user-supplied target JSON plus at least one command.

Implemented

  • Local JSON target loading
  • Repeated command arguments
  • Explicit plan-only output per device

Limitations

No SSH, Netmiko, credential handling, device connection, configuration push, validation command, backup, rollback, or log file is implemented.
