Network

Automated Device Configuration Utility

Created an SSH automation tool that pushes configuration files to routers and switches, validates changes, and logs results. Demonstrates infrastructure scripting skills and supports scalable network configuration management.

Code Example

from netmiko import ConnectHandler

def push_config(device, config_lines, log_path="config_push.log"):
    connection = ConnectHandler(**device)
    output = connection.send_config_set(config_lines)
    connection.save_config()
    connection.disconnect()

    with open(log_path, "a") as log_file:
        log_file.write(f"{device['host']}: {output}\n")

    return output

device = {
    "device_type": "cisco_ios",
    "host": "192.168.10.1",
    "username": "netadmin",
    "password": "***",
}

Project architecture

The utility opens an SSH connection through Netmiko, sends a configuration set, saves the running configuration, disconnects, and appends the device result to a log.

  • Device dictionaries describe connection targets.
  • Netmiko handles configuration transport.
  • Logging preserves output for operational review.

Features and expansion

Current features include SSH configuration delivery, save operations, disconnect handling, and per-device logging. Next additions should include dry-run mode, pre-change backups, validation commands, target allowlists, credential separation, rollback guidance, and failure tests.
