Support Automation Scripts

Created Python scripts that streamline repetitive help desk tasks such as log collection, system cleanup, configuration checks, and report generation. Reduced manual workload and improved consistency across troubleshooting workflows.

Code Example

import shutil
import tempfile
from pathlib import Path
from datetime import datetime

def collect_logs(destination):
    log_sources = [Path("C:/Windows/Logs"), Path.home() / "AppData/Local/Temp"]
    bundle = Path(destination) / f"logs_{datetime.now():%Y%m%d_%H%M}.zip"
    with tempfile.TemporaryDirectory() as staging:
        for source in log_sources:
            if source.exists():
                shutil.copytree(source, Path(staging) / source.name, dirs_exist_ok=True)
        shutil.make_archive(str(bundle.with_suffix("")), "zip", staging)
    return bundle

def clean_temp_files():
    temp_dir = Path(tempfile.gettempdir())
    removed = 0
    for item in temp_dir.glob("*"):
        try:
            if item.is_file():
                item.unlink()
                removed += 1
        except PermissionError:
            continue
    return removed

Project architecture

The support toolkit is organized around repeatable help-desk operations: collect useful logs, clean temporary data, check configuration, and produce a report that can be handed to the operator.

  • Small focused scripts keep tasks independently runnable.
  • Collected evidence supports troubleshooting decisions.
  • Report generation makes results consistent.
