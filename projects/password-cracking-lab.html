Cyber Security Training Prototype

Password Cracking Lab

A dependency-free demonstration that hashes locally supplied training text and compares it with a three-word in-memory dictionary.

Evidence snapshot

Source: Cybersecurity\password-cracking-lab

Run from repository root: python "Cybersecurity\password-cracking-lab\main.py"

Validation: Fully local and deterministic; no files, accounts, external tools, or network targets are used.

Implemented

  • Creates a hash from a local training value
  • Hashes three built-in candidate words for comparison
  • Reports whether a dictionary candidate matches

Limitations

No Hashcat integration, brute-force engine, wordlist file, salted-hash workflow, benchmark, account access, or external password data is included.
