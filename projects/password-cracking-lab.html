Password Cracking Lab

Conducted controlled password cracking exercises using Hashcat and Python in an isolated lab environment to understand hashing algorithms, brute-force and dictionary strategies, and defensive password policies. Documented results to strengthen knowledge of authentication weaknesses and mitigation techniques such as salting, slow hashing, and lockout policies.

Code Example

import hashlib

def generate_sample_hashes(passwords, algorithm="sha256"):
    hashes = {}
    for password in passwords:
        digest = hashlib.new(algorithm, password.encode()).hexdigest()
        hashes[password] = digest
    return hashes

# Lab-only dictionary attack demonstration against locally generated hashes
def dictionary_attack(target_hash, wordlist_path, algorithm="sha256"):
    with open(wordlist_path) as wordlist:
        for word in wordlist:
            word = word.strip()
            if hashlib.new(algorithm, word.encode()).hexdigest() == target_hash:
                return word
    return None

Project architecture

This lab keeps the exercise local and controlled: generate sample digests, read a supplied wordlist, hash each candidate with the selected algorithm, and stop when a digest matches the target.

  • Hash generation creates reproducible local test data.
  • Dictionary iteration provides a bounded educational workflow.
  • Algorithm selection makes the demonstration explicit.

Features and expansion

Current features include configurable hashing, local sample generation, wordlist comparison, and defensive lessons on salting and slow hashing. Next additions should include salted and slow-hash benchmarks, redacted results, validation, and edge-case tests.
