Cyber Security Prototype

Network Scanner

A dependency-free command-line prototype that performs sequential TCP connection checks against one explicitly supplied host and port list.

Evidence snapshot

Source: Cybersecurity\network-scanner

Run from repository root: python "Cybersecurity\network-scanner\main.py" 127.0.0.1 --ports 22,80,443

Validation: Safe against the loopback target; sends bounded TCP connection attempts and writes no files.

Implemented

  • Comma-separated port parsing
  • Sequential socket.connect_ex checks with a 0.3-second timeout
  • JSON output containing the host and detected open ports

Limitations

This is not multithreaded, does not expand CIDR ranges, and does not identify services or banners. Use only against systems you own or are authorized to test.
