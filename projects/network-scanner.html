Network Scanner

Created a Python-based multithreaded network scanner capable of probing IP ranges, detecting open ports, and identifying running services. Implemented socket-level communication, concurrency, and structured output formatting to support reconnaissance and network mapping tasks in authorized lab environments.

Code Example

import socket
from concurrent.futures import ThreadPoolExecutor

COMMON_PORTS = [21, 22, 23, 25, 80, 443, 3389]

def scan_port(host, port):
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        sock.settimeout(0.5)
        if sock.connect_ex((host, port)) == 0:
            return port
    return None

def scan_host(host):
    open_ports = []
    with ThreadPoolExecutor(max_workers=20) as executor:
        results = executor.map(lambda p: scan_port(host, p), COMMON_PORTS)
        open_ports = [p for p in results if p]
    return host, open_ports

Project architecture

The scanner accepts an authorized host, probes a defined set of common ports with bounded socket timeouts, runs checks concurrently, and returns structured open-port results.

  • Python socket probes isolate each host and port check.
  • ThreadPoolExecutor coordinates concurrent checks.
  • Structured results support reporting and export.

Features and expansion

Current features include timeout-bounded socket scanning, common-port discovery, concurrency, and host-level summaries. Next additions should include CIDR input, configurable ports, rate limiting, allowlists, service banners, JSON/CSV export, and timeout tests.
