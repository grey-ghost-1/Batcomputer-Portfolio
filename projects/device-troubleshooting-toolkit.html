Device Troubleshooting Toolkit

Developed a Python-based GUI application capable of diagnosing CPU load, RAM usage, disk health, driver issues, and network connectivity problems. Designed to replicate real help desk diagnostic workflows, providing structured output and actionable recommendations for system remediation.

Code Example

import psutil
import tkinter as tk

def run_diagnostics():
    cpu = psutil.cpu_percent(interval=1)
    memory = psutil.virtual_memory().percent
    disk = psutil.disk_usage("/").percent

    issues = []
    if cpu > 85:
        issues.append("High CPU load detected")
    if memory > 90:
        issues.append("Memory usage critical")
    if disk > 90:
        issues.append("Disk nearly full")

    return {"cpu": cpu, "memory": memory, "disk": disk, "issues": issues}

def show_report(report):
    window = tk.Tk()
    window.title("Device Diagnostics")
    for key, value in report.items():
        tk.Label(window, text=f"{key}: {value}").pack()
    window.mainloop()

Project architecture

The toolkit collects CPU, memory, and disk measurements, evaluates them against practical thresholds, and returns a structured report of detected issues and recommendations.

  • psutil gathers workstation health metrics.
  • Threshold checks classify resource pressure.
  • A Tkinter view presents the diagnostic report.

Features and expansion

Current features include CPU, RAM, and disk checks, issue classification, actionable recommendations, and a basic GUI report. Next additions should include driver and network checks, exportable reports, configurable thresholds, and tests for boundary values.
