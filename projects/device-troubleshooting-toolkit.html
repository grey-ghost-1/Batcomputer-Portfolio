IT Support Prototype

Device Troubleshooting Toolkit

A command-line health classifier that evaluates three user-supplied utilization percentages against fixed thresholds.

Evidence snapshot

Source: IT Support\device-troubleshooting-toolkit

Run from repository root: python "IT Support\device-troubleshooting-toolkit\main.py" --cpu 32 --memory 71 --disk 94

Validation: Fully local and deterministic; uses supplied values and makes no system changes.

Implemented

  • CPU, memory, and disk percentage inputs
  • Threshold-based healthy or attention state
  • Structured issue list in JSON output

Limitations

This is a CLI calculation, not a GUI or live diagnostic scanner. It does not inspect drivers, network connectivity, processes, hardware, or operating-system state.
