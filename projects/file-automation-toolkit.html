Software Dry-Run Prototype

File Automation Toolkit

A read-only file organization planner that groups immediate child files by extension and prints hypothetical destinations.

Evidence snapshot

Source: Software Automation\file-automation-toolkit

Run from repository root: python "Software Automation\file-automation-toolkit\main.py" .

Validation: Read-only by construction; no files or directories are created, moved, renamed, deleted, or compressed.

Implemented

  • Immediate file discovery for one directory
  • Extension-based destination planning
  • JSON dry-run output

Limitations

No mutation, pattern renaming, recursive organization, archive compression, synchronization, duplicate handling, rollback, or scheduling is implemented.
