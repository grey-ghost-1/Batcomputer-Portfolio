File Automation Toolkit

Developed a suite of Python automation scripts capable of organizing directories, renaming files based on patterns, compressing archives, and syncing folder structures. Designed for efficiency and repeatability, reducing manual workload and improving file management workflows.

Code Example

import shutil
from pathlib import Path

def organize_by_extension(folder: Path):
    for file in folder.iterdir():
        if file.is_file():
            category = file.suffix.lstrip(".").lower() or "misc"
            target_dir = folder / category
            target_dir.mkdir(exist_ok=True)
            shutil.move(str(file), str(target_dir / file.name))

def rename_by_pattern(folder: Path, prefix: str):
    for index, file in enumerate(sorted(folder.glob("*.*")), start=1):
        new_name = f"{prefix}_{index:03d}{file.suffix}"
        file.rename(folder / new_name)

def archive_folder(folder: Path, destination: Path):
    shutil.make_archive(str(destination), "zip", str(folder))

Example

Running the toolkit against a cluttered downloads folder:

$ python file_toolkit.py --organize C:\Downloads

Archived C:\Downloads\pdf to C:\Downloads\pdf.zip

Project architecture

The toolkit applies focused filesystem operations: classify files by extension, move them into category folders, rename matching files predictably, and create compressed archives for repeatable organization.

  • Path iteration identifies eligible files.
  • Extension rules select destination folders.
  • shutil performs moves and archive creation.
  • Deterministic naming supports repeatable runs.

Features and expansion

Current features include extension-based organization, pattern renaming, ZIP archiving, and repeatable directory workflows. Next additions should include dry-run mode, collision handling, exclusion rules, operation logs, restore manifests, and tests for nested or empty folders.
