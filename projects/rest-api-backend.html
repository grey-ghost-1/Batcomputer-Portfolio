REST API Backend

Implemented a FastAPI backend with JWT authentication, structured routing, and full CRUD operations. Built reusable service layers, validation schemas, and secure authentication flows, showcasing backend engineering fundamentals and API lifecycle understanding.

Code Example

from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer
from pydantic import BaseModel
import jwt

app = FastAPI()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")
SECRET_KEY = "dev-secret"

class Item(BaseModel):
    name: str
    quantity: int

def get_current_user(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
        return payload["sub"]
    except jwt.PyJWTError:
        raise HTTPException(status_code=401, detail="Invalid token")

@app.post("/items")
def create_item(item: Item, user: str = Depends(get_current_user)):
    return {"owner": user, "item": item}

Project architecture

The API uses FastAPI routes, Pydantic validation, OAuth2 bearer-token extraction, JWT decoding, and dependency-based user resolution before creating an authenticated item.

  • Pydantic models validate request data.
  • OAuth2PasswordBearer extracts the access token.
  • JWT validation resolves the current user.
  • Route dependencies protect the create operation.

Features and expansion

Current features include typed request validation, JWT authentication, bearer-token dependencies, protected CRUD direction, and structured API responses.
