Software Validation Prototype

REST API Backend

Despite the retained project path and title, the current implementation is one dependency-free item-validation function and command-line wrapper, not an HTTP API.

Evidence snapshot

Source: Software Automation\rest-api-backend

Run from repository root: python "Software Automation\rest-api-backend\main.py" widget --quantity 4

Validation: Fully local, in-memory, deterministic, and side-effect free.

Implemented

  • Non-empty item-name validation
  • Non-negative quantity validation
  • Owner-scoped dictionary construction and JSON output

Limitations

No FastAPI, Flask route, HTTP server, REST interface, JWT, authentication, database, persistence, service layer, schema library, or read/update/delete operations are implemented.
