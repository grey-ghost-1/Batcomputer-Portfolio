Cyber Security Prototype

SIEM Log Analyzer

A focused parser that counts failed-password log lines by user and IP address and filters them by a supplied threshold.

Evidence snapshot

Source: Cybersecurity\siem-log-analyzer

Run from repository root: python "Cybersecurity\siem-log-analyzer\main.py" path\to\auth.log --threshold 3

Validation: Read-only, but requires a user-supplied log file; no sample log is bundled.

Implemented

  • Regex matching for Failed password for USER from IP lines
  • Counts matching user/IP pairs
  • Returns pairs that meet the threshold

Limitations

This is not a SIEM pipeline. It does not ingest multiple formats, parse timestamps, correlate events, categorize event types, detect broader anomalies, or persist findings.
