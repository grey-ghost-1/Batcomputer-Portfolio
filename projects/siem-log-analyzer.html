SIEM Log Analyzer

Built a simulated SIEM ingestion pipeline that parses logs, identifies anomalies, and flags suspicious patterns. Developed regex-based detection, timestamp correlation, and event categorization to mirror real-world Blue Team log analysis workflows.

Code Example

import re
from collections import defaultdict

FAILED_LOGIN = re.compile(r"Failed password for (\S+) from (\d+\.\d+\.\d+\.\d+)")

def analyze_log(path, threshold=5):
    attempts = defaultdict(int)
    with open(path) as log_file:
        for line in log_file:
            match = FAILED_LOGIN.search(line)
            if match:
                user, ip = match.groups()
                attempts[(user, ip)] += 1

    flagged = {key: count for key, count in attempts.items() if count >= threshold}
    return flagged

Project architecture

The analyzer reads an authentication log, extracts failed-login identities and source addresses with a compiled pattern, aggregates repeated attempts, and returns entries that meet the configured threshold.

  • Regex extraction identifies user and source IP fields.
  • Defaultdict aggregation groups repeated events.
  • Threshold filtering creates actionable findings.

Features and expansion

Current features include Python file processing, user/IP correlation, configurable thresholds, and structured flagged-event output. Next additions should include multiple log formats, timestamp windows, severity levels, JSON export, parser fixtures, and searchable investigation history.
