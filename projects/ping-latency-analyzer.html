Network Diagnostic Prototype

Ping & Latency Analyzer

A sequential wrapper around the operating system's ping command that records reachability and raw command output for supplied hosts.

Evidence snapshot

Source: Network\ping-latency-analyzer

Run from repository root: python "Network\ping-latency-analyzer\main.py" 127.0.0.1

Validation: Spawns bounded system ping processes and sends ICMP traffic; the documented target is loopback.

Implemented

  • One bounded two-packet ping per supplied host
  • OS-aware ping flag selection
  • Reachability boolean and raw stdout output

Limitations

Checks are sequential, not multithreaded or continuous. Packet-loss percentages and latency statistics are not parsed, stored, graphed, or alerted on.
