Network

Ping & Latency Analyzer

Developed a multithreaded Python tool that performs continuous ping tests, packet loss detection, and latency analysis across multiple hosts. Useful for diagnosing intermittent network issues and monitoring connection stability.

Code Example

import subprocess
import re
from concurrent.futures import ThreadPoolExecutor

def ping_stats(host, count=10):
    result = subprocess.run(
        ["ping", "-n", str(count), host], capture_output=True, text=True
    )
    loss_match = re.search(r"\((\d+)% loss\)", result.stdout)
    latency_match = re.search(r"Average = (\d+)ms", result.stdout)
    return {
        "host": host,
        "packet_loss_percent": int(loss_match.group(1)) if loss_match else None,
        "avg_latency_ms": int(latency_match.group(1)) if latency_match else None,
    }

def analyze_hosts(hosts):
    with ThreadPoolExecutor(max_workers=10) as executor:
        return list(executor.map(ping_stats, hosts))

Project architecture

The analyzer runs repeated ping tests across multiple hosts, parses packet loss and average latency from command output, and combines the results into a comparative connectivity report.

  • Subprocess calls collect platform-specific ping output.
  • Regex parsing extracts loss and latency metrics.
  • ThreadPoolExecutor runs host checks concurrently.

Features and expansion

Current features include multi-host testing, packet-loss detection, average latency, concurrency, and structured results. Next additions should include platform adapters, timeout controls, percentile latency, continuous sampling, CSV export, and tests for missing metrics.
