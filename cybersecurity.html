Cyber Security Labs

Five bounded training prototypes demonstrate local TCP checks, failed-login parsing, offline advisory matching, training-hash comparison, and controlled response-reflection checks.

Safety and scope

  • Network checks are limited to user-supplied hosts and ports
  • Advisory matching uses local JSON files and makes no CVE API requests
  • Password examples use locally generated training data only
  • The OWASP example checks reflection in a controlled response string; it does not attack Juice Shop
  • None of these scripts is a full scanner, SIEM, vulnerability manager, or penetration-testing suite

Labs & Prototypes

  • Network Scanner Prototype — Performs bounded TCP connection checks for one host and an explicit port list; it does not scan IP ranges or identify services.
  • Failed-Login Log Analyzer — Parses matching log lines and reports user/IP pairs at a threshold; it is not a SIEM ingestion or correlation platform.
  • Offline Advisory Matcher — Cross-references two local JSON files by product and version; it does not query NVD or calculate live risk.
  • Training Hash Comparison — Compares hashes created from a small local word list; it does not invoke Hashcat or perform brute-force attacks.
  • Reflection Check Prototype — Detects whether a marker is reflected in a supplied training response; it does not execute OWASP exploits.
