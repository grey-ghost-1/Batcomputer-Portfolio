IT Support

This category reflects the operator side of the Batcomputer build: making tools simple to launch, fast to troubleshoot, and clear enough to support real use instead of demo-only interaction.

Core capabilities

  • Support-focused troubleshooting and runtime recovery
  • User-facing assistant UX and actionable live responses
  • Launcher, environment, and process management
  • System status visibility and operational guidance
  • Automation that reduces friction for everyday technical tasks

Implemented work

  • One-command alfred launcher for starting the latest local site
  • Stale-server detection and cleanup when the wrong Python process is running
  • Live console improvements that show Alfred responding immediately
  • Voice-input and spoken-response flow for hands-free interaction
  • Faster website and weather answers through direct support-style routing

Featured Projects

  • Device Troubleshooting Toolkit — Developed a Python-based GUI application capable of diagnosing CPU load, RAM usage, disk health, driver issues, and network connectivity problems. Designed to replicate real help desk diagnostic workflows, providing structured output and actionable recommendations for system remediation.
  • Messaging/RCS Diagnostic Simulator — Built a simulation tool to test RCS/SMS fallback behavior, carrier routing issues, and message delivery reliability. Used to analyze inconsistent messaging performance across devices and networks, improving understanding of telecom protocols and troubleshooting methods.
  • System Health Checker — Engineered an automated scanning utility that evaluates system updates, driver status, storage capacity, and network configuration. Consolidated results into clear reports, enabling faster identification of system vulnerabilities and maintenance needs.
  • Network Diagnostic Utility — Implemented a suite of network diagnostic tools including ping, traceroute, DNS lookup, and latency measurement. Designed to assist in identifying connectivity issues, routing problems, and DNS misconfigurations in real-world support environments.
  • Support Automation Scripts — Created Python scripts that streamline repetitive help desk tasks such as log collection, system cleanup, configuration checks, and report generation. Reduced manual workload and improved consistency across troubleshooting workflows.
