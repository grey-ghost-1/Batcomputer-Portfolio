IT Support Labs

Five small command-line tools demonstrate health classification, disk reporting, DNS and ping checks, messaging fallback simulation, and dry-run log-collection planning.

Demonstrated scope

  • Classifies supplied CPU, memory, disk, and connectivity values
  • Reports free disk space for a supplied path
  • Runs bounded DNS and system ping diagnostics for one host
  • Simulates RCS-to-SMS fallback without contacting a carrier
  • Creates plan-only log collection output without copying or deleting files

Current limitations

These prototypes do not inspect drivers, install updates, clean systems, change configuration, contact telecom services, or provide a desktop GUI. Results are local summaries based on supplied values or bounded operating-system commands.

Labs & Prototypes

  • Device Health Classifier — Produces a structured report from supplied metrics; it does not inspect a live workstation or drivers.
  • Messaging/RCS Simulator — Applies deterministic local fallback rules; it does not test carrier routing or delivery.
  • Disk Health Checker — Reports free-space values and a threshold-based state for one path.
  • Network Diagnostic Utility — Performs DNS resolution and a bounded ping; it does not provide traceroute or configuration remediation.
  • Log Collection Planner — Reports which matching files would be collected; it does not copy logs, clean systems, or generate operational reports.
